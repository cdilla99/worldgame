# Local fonts

Orbitron is the retro-futurist display face. Inter remains the body and control
face for compact phone layouts. Sora remains available as a fallback.

Orbitron source: https://github.com/google/fonts/tree/main/ofl/orbitron
License: `OFL-Orbitron.txt` (SIL Open Font License 1.1).
The variable TTF is kept as the source; the WOFF2 is served by the app.
The EARTHLING SVG wordmark uses outlined Orbitron glyphs at weight 700 so
the logo renders independently of font loading.

Interface palette is defined in `../../retro-theme.css`:

- Mandarin Orange: `#F28C28`
- Forest Green: `#1B4D3E`
- Crest Yellow: `#F4C542`

Pale green and warm white are used for readable text on dark surfaces.
Country flags and geographic artwork retain their original colours.
